## Goal

You can match pinned dependencies against OSV advisory ranges, gate a Trivy report with severity thresholds and expiring waivers, and place composition analysis within the four Cs of cloud native security.

In the lesson: This is a lockfile generated by pip compile from a short requirements in file. The header says how it was produced, so anyone can regenerate it the same way. Each package is pinned with a double equals sign to one exact version. The via comments are the useful part for security. Requests was asked for directly, and the other four are only here because requests needs them. When a finding lands on U R L lib three, the via line tells you who pulled it in, and so whether the fix is bumping U R L lib three or bumping requests. Notice that editing the requests pin alone would not change the U R L lib three line in this file. The lockfile keeps every version exactly where it is until someone regenerates it.
